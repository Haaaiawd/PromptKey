# Phase 1 高保真原型

直接用浏览器打开即可，无构建依赖。每个原型右上角均可切换 **明/暗** 与 **中/英**。

| 文件 | 内容 |
|---|---|
| `main-window.html` | 合并后主窗口：导航 4 项（提示词/模板库/记录/设置）、⭐pin 内联、轮盘镜像栏、搜索（#tag/@name/c: 前缀）、卡片/列表切换、编辑抽屉、模板库、记录、设置、Toast、轮盘预览（内嵌 A 案缩影） |
| `wheel-a-radial.html` | **轮盘 A 案（推荐）**：280px Mini 径向，跟随光标弹出，打字过滤，数字键/点击注入，petal 交错动画 |
| `wheel-b-arc.html` | 轮盘 B 案：120° 半弧形菜单，光标处向右展开，最轻视觉 |
| `wheel-c-palette.html` | 轮盘 C 案：320px 紧凑列表浮条，Spotlight 式，搜索最强，↑↓/Enter 操作 |

## 试用方法

- 主窗口：左侧底部切主题/语言；点 ⭐ 体验 pin 内联；点"轮盘预览"看 A 案动效
- 轮盘原型：页面上**点击任意处 = 模拟热键**，轮盘在点击位置弹出；打字过滤 / 数字键 1-6 选中 / Esc 或点击外部关闭；选中后会在模拟应用窗口里"注入"文本

设计依据见 `../UI_UX_REDESIGN.md` §3（候选对比与推荐理由）。
